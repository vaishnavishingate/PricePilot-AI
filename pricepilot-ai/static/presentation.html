PricePilot AI: Dynamic Pricing & Revenue Intelligence

An advanced dynamic price optimizer and forecasting model tailored to the Brazilian E-Commerce (Olist) dataset. Prepared for internship project evaluation.

  • Machine Learning Driven: Random Forest & XGBoost price elasticity regressions.
  • Comprehensive Analytics: Visualizes competitor tracking, forecasting timelines, and revenue-profit simulations.
  • Modern Technical Stack: FastAPI Backend, SQLite relational model storage, and responsive glassmorphic SPA frontend.
Project Requirements

Core Functional Modules

Features implemented systematically in alignment with the high-level roadmap guidelines:

  • User & Role Management: Role-Based Access Control protecting sensitive ML configs for Admins, Managers, and Analysts.
  • Olist Dataset Loading: Seamless parsing and database loading of products, order items, and orders.
  • Price Prediction Engine: Machine learning algorithms that map consumer purchase behavior to optimal pricing.
  • Time-Series Forecasting: Predicting short-term (7 to 30 days) and long-term (1 year) demand projections.
Architecture Diagram

System Architecture Design

The PricePilot AI ecosystem utilizes a highly decoupled, modern architectural flow:

  • Access Gateway: FastAPI serves as the REST API hub with JWT token verification middleware.
  • Data Layer: SQLite handles indexed queries across relational schemas with zero configuration dependencies.
  • AI / ML Core: Models (Random Forest / XGBoost) trained on historical demand and competitor signals.
  • Interactive Frontend: HTML5/CSS3 dynamic SPA using Chart.js to map predictions in real time.
Relational Schema

Relational Database Modeling

Unified schema design matching standard Olist dataset keys and custom attributes:

  • olist_products: Primary key `product_id`, category name, weight, and simulation variables (cost, base price).
  • olist_order_items: Links order history, sellers, pricing points, and regional freight costs.
  • olist_orders: Mapped timestamps of user purchases to analyze date-based seasonality.
  • competitor_prices: Logged pricing points from rival merchants to compute benchmark comparisons.
AI / ML Engine

AI Model Features & Optimization

Mathematical modeling of pricing sensitivity to secure revenue-maximizing coordinates:

  • Feature Pipeline: Extracts temporal vectors (month, day of week), lag values (ARIMA-like), stock turnover indices, and price ratios.
  • Pricing Optimization: Predicts units sold for a grid of 100 prices between cost and base bounds to isolate the peak profit: \(\text{Profit} = (P - C) \times Q(P)\).
  • Forecasting Options: Allows testing Prophet, ARIMA, XGBoost, Random Forest, and LSTM algorithms on customer purchase timelines.
